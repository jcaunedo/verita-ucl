# Verita AI UCL

The Unified Content Library is the shared React component library for Verita AI frontend apps. It's built with
React 19, TypeScript, Tailwind CSS 4, Untitled UI, and React Aria.

## Making a change

1. **Build it in Storybook.** Create or update the component with stories for every state it has: default, hover,
   disabled, error, loading, empty. `CLAUDE.md` covers the folder structure and conventions, and `DESIGN.md` the rules
   to follow.
2. **Export it** from `src/index.ts`, the library's public entry, so apps can import it.
3. **Get it reviewed:** design review in Storybook, code review in the pull request. Then merge to `main`.

## Finding your way around

Start with **Foundations**: the color tokens, type scale, and motion presets every component is built from. Those
pages are generated from `theme.css` and `src/lib/motion/`, so they're always current.

Each component has a **Docs** page with a live preview, an editable props table, and every variant. The sidebar groups
components by family, including:

| Family       | What's in it                                       |
| ------------ | -------------------------------------------------- |
| Buttons      | Buttons, links, and sidebar menu items             |
| Forms        | Inputs, selects, text areas, and tag inputs        |
| Overlays     | Modals, menus, and tooltips                        |
| Data Display | Avatars, badges, and tags                          |
| Feedback     | Alerts, toasts, and empty states                   |
| Cards        | Contract, offer, match, and application cards      |
| Navigation   | Sidebar and tabs                                   |
| Layouts      | Full-page prototype flows built from the above     |

## Contributing

Read `DESIGN.md` before you create or change a component. It records the design and component rules that took
iteration to land on. `CLAUDE.md` covers folder structure, the motion system, and how to add a component.
